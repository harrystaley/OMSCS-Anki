# OMSCS-Anki

Welcome to the **OMSCS-Anki** repository! This is a collaborative platform for enhancing and sharing Anki study materials specifically tailored to courses in the Georgia Tech Online Master of Science in Computer Science (OMSCS) program. Our goal is to provide a comprehensive collection of Anki decks that can help students efficiently review and retain course material.

## Features

- **Collaborative Deck Creation**: Contribute to existing decks or create new ones for various OMSCS courses.
- **Seamless Sharing**: Access decks via AnkiWeb or through the CrowdAnki plugin.
- **Diverse Topics**: Covering a wide range of subjects including AI, OS, version control, and more.
- **Community Driven**: Benefit from contributions by fellow students and educators.

## Setup and Installation

To get started with the OMSCS-Anki decks, follow these steps:

1. **Install Anki**: Download and install Anki from the [official website](https://apps.ankiweb.net/).
2. **CrowdAnki Plugin**: Install the CrowdAnki plugin to enable seamless import and export of decks. You can find it in the Anki add-ons section.
3. **Clone the Repository**: Use Git to clone the repository to your local machine.
   ```bash
   git clone https://github.com/yourusername/OMSCS-Anki.git
   ```
4. **Import Decks**: Open Anki, go to `File` -> `Import`, and select the desired deck from the cloned repository.

## Usage

Once you have imported the decks into Anki, you can start reviewing them:

- Open Anki and select the deck you want to study.
- Use Anki's built-in tools to customize your study sessions.
- Sync your progress with AnkiWeb to access your decks from any device.

## Contribution Guidelines

We welcome contributions from everyone! To contribute:

1. **Fork the Repository**: Make a personal copy of the repository by clicking the "Fork" button.
2. **Create a Branch**: Create a new branch for your feature or bug fix.
   ```bash
   git checkout -b feature-name
   ```
3. **Make Your Changes**: Enhance or create new decks.
4. **Submit a Pull Request**: Once your changes are ready, submit a pull request for review.

Please ensure your contributions adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
